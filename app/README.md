# 少抽 · 装到手机桌面

这是一个 PWA。装好之后：桌面上有独立图标，点开全屏运行（没有地址栏），断网也能记录。

**它需要一个网址。** 浏览器只允许从 `https://` 地址安装到桌面，本地文件（`file://`）不行 —— 这是浏览器的安全限制，绕不过去。所以只差最后一步：把这个文件夹放到一个免费的静态托管上。

---

## 一、拿到网址（5 分钟，二选一）

### 方案 A：GitHub Pages（免费、永久、推荐）

1. 注册 [github.com](https://github.com)（邮箱 + 密码，免费）
2. 右上角 `+` → **New repository**
   - Repository name 填 `shaochou`
   - 选 **Public**
   - 点 **Create repository**
3. 在新建的仓库页面点 **Add file → Upload files**
4. 把本文件夹**里面的内容**拖进去：
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icons/` 整个文件夹

   ⚠️ 拖的是文件夹**里面**的东西，不要把 `app` 文件夹本身拖进去，否则网址会多一层 `/app/`
5. 底部点 **Commit changes**
6. 进 **Settings → Pages**
   - Source 选 **Deploy from a branch**
   - Branch 选 `main`，目录选 `/ (root)`
   - 点 **Save**
7. 等 1～2 分钟刷新页面，顶部会出现你的网址，形如：
   `https://你的用户名.github.io/shaochou/`

### 方案 B：Vercel / Netlify / Cloudflare Pages

都支持把文件夹直接拖进去，免命令行，几分钟拿到 `https://xxx.vercel.app` 这样的网址。任意一个都行，效果一样。

> 已经有自己的网站或服务器？直接把这几样文件传到某个目录下也可以，只要地址是 https。

---

## 二、装到桌面

**iPhone（必须用 Safari，微信里打开的不行）**
1. Safari 打开上面的网址
2. 点底部中间的 **分享** 按钮
3. 往下滑，点 **添加到主屏幕** → 添加

**Android（Chrome / Edge）**
1. 浏览器打开网址
2. 右上角 **⋮** → **安装应用**（有的版本叫「添加到主屏幕」）
3. 确认

也可以在 App 内的「设置」页看到「装到桌面」，会按你的手机给出对应指引。

---

## 三、装好之后

- 桌面图标点开就是全屏 App，没有地址栏
- 断网也能记（第二次打开起，全部文件已缓存到本地）
- 数据存在这个网址的浏览器里，不联网、不上传

---

## 四、几件要知道的事

**数据是跟「网址 + 浏览器」绑定的。** 换了网址、换了浏览器，之前记的都不会跟过去。所以定下网址后别轻易改；要换的话，先在「设置 → 导出备份」存一份，到新的再「导入备份」。

**清浏览器数据会丢记录。** 建议隔一段时间导出一份备份。

**以后改了代码怎么更新？** 把 `sw.js` 里的 `CACHE = 'shaochou-v1'` 改成 `v2`、`v3`……再上传，用户下次打开才会拿到新版本。不改版本号，浏览器会一直用缓存里的旧文件。

---

## 五、装不上时

| 现象 | 原因 |
|---|---|
| 找不到「添加到主屏幕」 | iPhone 要在 Safari 里打开，微信/Chrome 内打开没有这个菜单 |
| 没有「安装应用」 | 网址不是 https，或者页面还没加载完；刷新一次再试 |
| 桌面图标是白底/截图 | `icons/` 没传全，或者路径大小写不对 |
| 打开是空白 | `index.html` 没在根目录；或者 `sw.js` 缓存了坏版本（换个浏览器无痕窗口验证） |
